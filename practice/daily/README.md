# Daily Practice

This folder is dedicated to daily Python exercises that help strengthen core programming concepts, improve problem-solving skills, and encourage consistent learning.

Each file should focus on a single topic so the practice stays simple, clear, and easy to review.

## Purpose

- Build confidence with Python fundamentals
- Practice one concept at a time
- Keep code small, readable, and easy to understand
- Track daily progress through focused exercises

## File Naming Convention

Create one file for each practice session using this format:

- `daily/YYYY-MM-DD_topic.py`

Examples:

- `daily/2026-09-25_variables.py`
- `daily/2026-09-26_conditionals.py`
- `daily/2026-09-27_loops.py`

## Guidelines

- Keep each file simple and focused on one concept
- Use clear, descriptive names for variables and functions
- Add brief comments only when they improve readability
- Avoid mixing unrelated topics in the same file
- Aim for clean, beginner-friendly code

## Suggested Workflow

1. Choose one Python topic to practice.
2. Write a small example or exercise in a new file.
3. Test and refine the code.
4. Review the result and note what you learned.

This structure makes daily practice easier to follow and helps build a strong foundation over time.
