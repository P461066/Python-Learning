# Python Practice Workspace

This folder is for your daily Python practice. Add new files here as you learn.

## Suggested layout

practice/
├── README.md
├── progress.md
├── daily/
│   ├── README.md
│   └── your_topic_today.py
├── projects/
│   └── README.md
└── notes/
    └── README.md

## How to use it

- Create one file per day or per topic.
- Use names like `2026-09-25_variables.py` or `day_01_lists.py`.
- Keep each file small and focused.
- Add a short note in `progress.md` after each session.

## Example

```python
# Topic: Variables
# Date: 2026-09-25

name = "Alice"
age = 25

print(name)
print(age)
```
