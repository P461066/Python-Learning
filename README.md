# Python-Learning

Python for embedded systems and IoT development.

## Overview

With an Electrical Engineering background and a focus on embedded systems and smart infrastructure, this repository documents my journey learning Python as a foundation for embedded control and IoT development.

## Learning Platforms

- **Brilliant** — Conceptual thinking, problem-solving, and understanding the reasoning behind code.
- **Coddy** — Hands-on implementation, writing, testing, and debugging Python.
- **YouTube** — Visual learning and real-world project breakdowns showing how embedded systems and IoT solutions are built.
- **MIT OpenCourseWare** — I am using the open-source course **[Introduction to Computer Science and Programming in Python](https://ocw.mit.edu/courses/6-0001-introduction-to-computer-science-and-programming-in-python-fall-2016/)** to strengthen my understanding of Python, computational thinking, algorithms, and programming fundamentals.

This combination helps me understand the logic, execute the code, and connect what I learn to practical applications.

## Why Python?

Python bridges hardware and the cloud. My objective is to develop efficient scripts capable of handling sensor data, automating facility systems, and interfacing with AWS IoT services for smart-building applications.

## What You'll Find Here

This repository contains Python concepts, examples, practice exercises, and insights I find useful throughout my learning journey. Content is added incrementally as I progress.

## Focus Areas

- Python fundamentals and problem-solving
- Logic building and algorithmic thinking
- Algorithms and computational thinking
- Embedded systems and IoT foundations
- Sensor data processing and automation
- Cloud and AWS IoT integration

## Long-Term Vision

To build reliable, energy-efficient embedded solutions for modern infrastructure.
